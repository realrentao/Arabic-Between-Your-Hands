# 《阿拉伯语在你手中》· 全套 8 册（Arabic Between Your Hands）

全球广泛使用的阿拉伯语教材《العربية بين يديك》的交互式网页版，由「涛子办事处 · مكتب تاوزى」整理。

## 目录结构
- `index.html` —— 全套 8 册总导航页
- `volume-1/` —— **第一册（已上线）**：阿中对照、可点击真人发音（edge-tts ar-AE-FatimaNeural）的交互式课程，含问候/家庭/日常/饮食礼拜/学习/职业/听说测试
- `volume-2/` ~ `volume-8/` —— 占位页（敬请期待），后续各册部署后替换

## 第一册内容
整理自原书页 23–282，覆盖单元：问候与相识、家庭、日常生活·住所与作息、食物与饮品·礼拜、学习、工作·职业·自测、听力与口语测试。
